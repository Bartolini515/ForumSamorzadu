# Forum Samorządu

Forum Samorządu to aplikacja webowa stworzona z myślą o usprawnieniu organizacji pracy samorządu szkolnego ZSET w Lesznie. Projekt został zaprojektowany jako centralne miejsce do zarządzania wydarzeniami i zadaniami.

Aplikacja działa jako SPA (Single Page Application), dzięki czemu zapewnia szybkie i płynne działanie bez potrzeby przeładowywania stron. System został zbudowany z wykorzystaniem nowoczesnych technologii frontendowych i backendowych, skupiając się na praktycznym zastosowaniu oraz wygodzie użytkowników.

Projekt powstał w celu zastąpienia rozproszonych metod organizacji bardziej uporządkowanym i wygodnym rozwiązaniem, które pozwala lepiej planować wydarzenia, zarządzać obowiązkami oraz koordynować działania całego zespołu.

## Funkcjonalności

### Dashboard

Centralny panel aplikacji umożliwiający szybki dostęp do najważniejszych informacji, wydarzeń oraz aktywności użytkowników.

### Zarządzanie użytkownikami

- Dodawanie oraz edycja użytkowników
- System ról i uprawnień
- Kontrola dostępu do wybranych funkcjonalności systemu

### Kalendarz wydarzeń

Rozbudowany system kalendarza umożliwiający tworzenie, organizowanie oraz śledzenie wydarzeń szkolnych i działań samorządu.

![Kalendarz](https://github.com/user-attachments/assets/3f974693-a997-414c-a7a5-38835ec57acd)

Każde wydarzenie posiada własny widok szczegółów wraz z dodatkowymi informacjami oraz przypisanymi zadaniami.

### System zadań

System umożliwiający tworzenie i przypisywanie zadań do konkretnych wydarzeń. Użytkownicy mogą samodzielnie przypisywać się do wybranych obowiązków lub zostać przypisani przez administratorów.

![Zadania](https://github.com/user-attachments/assets/0cbab490-5fbd-4215-8d97-0c0efd52097c)

### Plan lekcji i organizacja sal

Moduł planu lekcji zawiera dodatkowe funkcje wspierające codzienną organizację działań w szkole:

- sprawdzanie wolnych sal
- podgląd aktualnie odbywających się lekcji
- sprawdzanie obecnych klas
- planowanie przejść po klasach

![planlekcji](https://github.com/user-attachments/assets/66323033-f5ba-40af-a39d-44d1f02a7f8f)

### System powiadomień email

Automatyczne powiadomienia email informujące użytkowników o nowych wydarzeniach, zmianach oraz przypisanych zadaniach.

- SPA Architecture

## Cel projektu

Celem projektu było stworzenie nowoczesnego systemu organizacyjnego dla samorządu szkolnego, który ułatwia planowanie wydarzeń, komunikację oraz zarządzanie obowiązkami. Aplikacja skupia się na praktycznym wykorzystaniu w codziennej pracy zespołu i eliminuje wiele problemów związanych z ręczną organizacją działań.
